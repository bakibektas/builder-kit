# Deliverables

Every document produced for the user is saved here: an analysis, a report, a brief, a design
note, a comparison. Name it `YYYY-MM-DD-<short-title>.md`, commit it with the project, and
name it in that session's journal entry so it can be found again.

Nothing the user might need again lives only in the chat, or in a folder the tool keeps
somewhere else on the machine. If it was worth producing, it is worth committing here.

This `artifacts/` folder holds deliverables. `docs/` holds the project records that help
the next session continue: status, journal, decisions, lessons and research notes.

Large or binary source material that a deliverable refers to gets its own subfolder next to
that deliverable, named after it.
