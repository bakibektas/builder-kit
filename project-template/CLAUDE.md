## Where the working memory lives

This project keeps its state in `docs/`. Read the instruction header inside each file.

- `docs/STATUS.md`: current focus, next action, blocked-on, task list. Read this in full at
  the start of every session. Overwrite it freely.
- `docs/JOURNAL.md`: session log, newest first. Read only the top entry at session start.
- `docs/DECISIONS.md`: direction-changing decisions with a mandatory WHY. Search, do not read.
- `docs/LESSONS.md`: the curated record fed by corrections. Search for keywords relevant to
  the task; do not read the file whole.
- `docs/RESEARCH.md`: findings already paid for, with sources and dates. Search it before
  researching anything; do not read the file whole.

At session end: overwrite `STATUS.md`, prepend one entry to `JOURNAL.md`, and append to
`DECISIONS.md`, `LESSONS.md` or `RESEARCH.md` if any of them occurred. Nothing written is
nothing remembered.
