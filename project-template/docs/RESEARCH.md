# Research

<!--
HOW TO USE THIS FILE

Append-only research record, newest first. One entry per question answered. Entries are
curated, never raw dumps: an entry holds what a future session needs so the research is not
repeated, and nothing else.

- Search this file for keywords before starting any new research on a topic. Never read it
  whole: what you need is one entry, not the file.
- Every source carries a URL and a date. Mark which claims were verified against a primary
  source and which are inferred or come from somewhere secondary. An unmarked claim reads as
  verified, and that is how a guess becomes a fact three weeks later.
- Bulky raw material stays out: long quotes, tables of numbers, transcripts. If an
  investigation outgrows an entry, give it its own document in the project and point the
  entry at it.
- Cap: ~200 lines. When it grows past that, MOVE the oldest entries: cut them from here and
  paste them into `docs/research-archive.md`, creating that file if needed. Move content
  between files; never delete a file, and never drop an entry.
- Refer to people by role, never by name. No personal data of any kind.

Entry format:

### YYYY-MM-DD: <the question asked>
- **Verdict:** <the answer in two to five lines, plain language first>
- **Sources:** <url (date, verified/secondary)> <repeat>
- **Confidence:** <percent, with the main caveat>
- **Informed:** <the decision, task, or deliverable this fed, or "none yet">

Delete the EXAMPLE block once real entries exist.
-->
